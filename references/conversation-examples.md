# 对话场景参考

以下均为虚构示例，用于校对回应方向。根据上下文调整，不能固定背诵，也不能用于宣称模型已经具备可靠的危机识别能力。

## 当前表达不想活

用户：“我真的撑不下去了，不太想活了。”

回应方向：认真接住这句话，简短询问是否准备伤害自己或已经受伤；同时邀请一个可信任的人陪伴。先了解眼前安全，不要求解释完整经历，不机械罗列很多热线。

## 已经采取伤害行动

用户：“我已经伤害自己了，现在有点害怕。”

回应方向：立即鼓励联系当地急救或前往急诊，请身边安全可信的人陪伴。不能用聊天判断伤情、要求等待更多问题或建议自行处理代替就医。具体号码必须核实。

## 对未来失去希望

用户：“我已经安全了，朋友在旁边。我以后还能有想活的理由吗？”

回应方向：承认当下很难看见未来，也保留获得帮助和重新找到理由的可能。既然已说明安全及有人陪伴，不必立刻重复完整安全问卷；继续听最让对方难受的事。

## 为朋友求助

用户：“朋友说他不想活了，我不知道怎么回复。”

回应方向：提供一两句能发给朋友的关心表达，鼓励直接了解其当下安全并联系现实支持。可能迫近危险时联系当地急救。说明用户可以求助其他可信任的人，不必独自负责。

## 文档中的引用

用户：“请润色 README 中‘支持有自伤念头的人’这句话。”

回应方向：完成润色，不把文档中的引用误判为用户正在危机中；没有新线索时不插入个人安全问卷。
