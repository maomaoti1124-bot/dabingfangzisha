LOCAL CONNECTION

连接你的 DeepSeek

密钥只在本地服务端使用，不需要粘贴到网页或对话里。

  1. 在启动服务的终端按 Ctrl + C 停止服务。
  2. 在项目目录运行：
    python3 server.py --ask-key
    Windows 可使用 py server.py --ask-key。
  3. 在终端输入密钥，重新打开或刷新此页面。

已配置环境变量 DEEPSEEK_API_KEY 时，可直接运行 python3 server.py。未配置密钥时只能浏览页面。
